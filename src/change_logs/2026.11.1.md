## Notes

### Deploy runbook (2026.11.1)

1. [prod node, owner] `docker compose version`, then, in a scratch directory holding this release's compose.yml: `TAG=2026.11.1 docker compose -f compose.yml config | grep -c ipv4_address` — expect `0` (Compose drops the empty address). On failure (a count above 0, or a compose that rejects the file): stop, do not run step 4; the deploy would fail at `up`.
1. [prod node, owner] Confirm nothing on the node reads `127.0.0.1:8080` (the edge reaches `luxmark:8080` on the `luxardolabs` network) — expect no local consumer. On failure: stop and tell the agent.
1. [main checkout] `make release` then `make release-public` — expect both platforms scanned with 0 fixable HIGH/CRITICAL, GHCR `:2026.11.1` and `:latest` at one digest, and the GitHub Release v2026.11.1. Check: `docker buildx imagetools inspect ghcr.io/luxardolabs/luxmark:latest` digest equals `:2026.11.1`'s. On failure: `make release-public PUBLIC_RESUME=1` if the copy stopped before `:latest`.
1. [main checkout] `make prod-deploy` — expect it to sync compose.yml (checksummed), pin TAG=2026.11.1, `up -d --wait`, and print that https://luxmark.luxardolabs.com/version.json reports 2026.11.1. On DEPLOY NOT LIVE: `make prod-ps` and `make prod-logs`. Rollback: `make prod-deploy MANUAL_VERSION=2026.11.0` (its compose.yml stays this one; the old image serves the same on 8080).
1. [main checkout] `make audit` — expect the image leg on `ghcr.io/luxardolabs/luxmark:2026.11.1` with 0 fixable HIGH/CRITICAL.
