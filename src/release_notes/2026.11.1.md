# 2026.11.1 — 2026-11-18

A security update for the LuxMark image, and a simpler way to run it yourself.

Surfaces in these notes: `Editor` (the LuxMark site you write in) and `Docker` (the image you can run yourself).

## IMPROVED

- **Running LuxMark with Docker Compose** `Docker` — The compose setup now sits behind your reverse proxy and no longer opens a port on your machine; to serve LuxMark on a port directly, run `docker run -d -p 8080:8080 ghcr.io/luxardolabs/luxmark:2026.11.1` (see docs/DOCKER.md).

## FIXED

- **Security fixes** `Editor` `Docker` — The web server inside LuxMark is updated to close three high-severity security issues in a library it ships with.
