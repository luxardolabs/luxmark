# 2026.10.0 — 2026-10-10

A security release: the editor is harder to attack, and the image it ships in is patched.

These notes use two surface labels: `Editor` is the LuxMark page in your browser, and `Self-hosting` is the Docker image you run yourself.

## IMPROVED

- **Stronger protection against injected scripts** `Editor` — Your browser now refuses to run any script that isn't one of LuxMark's own published files, so content pasted or rendered into a document can't run code in the page.
- **Patched system packages** `Self-hosting` — The image ships with the latest security updates for its operating system, clearing 10 known high-severity vulnerabilities.
- **Every release is security-checked before publishing** `Self-hosting` — A release that would ship a known high-severity vulnerability is now stopped before it's published, for every processor type the image supports.

## FIXED

- **Container shown as unhealthy while working fine** `Self-hosting` — If you run LuxMark with the provided compose file, its health check now reports correctly.
