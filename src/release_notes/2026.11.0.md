# 2026.11.0 — 2026-11-05

Security fixes for the server that runs LuxMark. The editor itself is unchanged.

`Editor` is LuxMark's only surface: the hosted editor at luxmark.luxardolabs.com and the self-hosted image.

## FIXED

- **Security updates** `Editor` — The server behind your editor has the latest security patches, including one rated critical.

## IMPROVED

- **Harder to tamper with** `Editor` — The program that serves the editor can no longer change the editor files your browser loads.
- **Reliability** `Editor` — The hosted editor is the last thing stopped when its server runs short on memory, and the live version is now checked for known vulnerabilities as well as each new release.
