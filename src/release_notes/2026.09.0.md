# LuxMark 2026.09.0

## The version number changed, and that is the only thing you need to notice

LuxMark is now versioned by date: **2026.09.0** instead of 1.0.5. Nothing about the editor changed for you — same interface, same documents, same `localStorage`. If you pin a Docker tag, pin `2026.09.0`.

## Your documents are better protected

LuxMark renders your markdown in your own browser, and it borrows a handful of well-known libraries from public CDNs to do it — a markdown parser, syntax highlighting, math rendering, PDF export.

Two of those were being loaded **without a version**, meaning the CDN could serve newer code at any moment without anyone here deciding to update. Every library is now locked to an exact version, and every one is checked against a cryptographic fingerprint when it loads. If a CDN ever served something different from what we published against — corrupted, substituted, or tampered with — your browser now refuses to run it rather than running it silently.

Rendered markdown also passes through a dedicated sanitizer before it is shown. Your own documents were never at risk from each other, but this closes the door before any future feature — sharing a document by link, opening a file, pasting formatted text — could open it.

## Nothing you need to do

No migration, no settings change, no export/re-import. Your saved work is untouched.

If you self-host: the deploy now requires you to name the version you want (`TAG=2026.09.0` in `.env`) rather than defaulting to `latest`, so a container restart can never quietly move you to a different build. Copy `.env.example` to `.env` and set it once.
